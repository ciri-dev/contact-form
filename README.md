# Contact Form

Este es un proyecto basado en los retos de [roadmap.sh](https://roadmap.sh/projects/contact-form). El objetivo principal es construir un formulario de contacto accesible y estructurado utilizando únicamente HTML semántico y validación nativa del navegador, sin emplear JavaScript ni estilos CSS en esta fase inicial.

## Objetivos del Proyecto

- **HTML Semántico y Estructura:** Utilizar las etiquetas adecuadas (`<form>`, `<fieldset>`, `<legend>`, `<select>`, `<textarea>`, etc.) para construir un formulario robusto.

- **Accesibilidad:** Vincular correctamente cada control de formulario con su respectiva etiqueta mediante los atributos for e id, evitando depender únicamente de marcadores de posición (placeholders).

- **Agrupación de Elementos:** Organizar las opciones de selección múltiple (como los botones de opción o radio buttons) dentro de un `<fieldset>` acompañado de su respectivo `<legend>`.

- **Validación del Navegador:** Implementar atributos nativos de validación (required, minlength, type="email") para asegurar la integridad básica de los datos antes del envío.

- **Simulación de Envío (POST):** Configurar el formulario con una URL de acción simulada y el método method="post" para comprobar mediante las herramientas de desarrollo del navegador (DevTools) la correcta generación de la solicitud HTTP con sus pares de nombre y valor.

## Tecnologías Utilizadas

- **HTML5**
